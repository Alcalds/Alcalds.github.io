Challenge and response

Replacing repetitive document handling with a traceable workflow.

01

The operational problem

Incoming reports and supporting files required repeated inbox checking, relevance screening, downloading, classification, folder creation, and tracker updating. Historical messages also needed to be organized without duplicating records or interrupting live processing.

02

My role

I planned the workflow, translated the document-handling process into rules, developed the Apps Script solution, tested live and historical modes, reviewed execution logs, and refined classification and duplicate-control behavior.

03

The solution

The deployed workflow checks incoming mail on a schedule, screens messages, classifies each attachment, creates the required Drive path, saves the file, updates a Sheets register, records processing status, and sorts entries chronologically.

Scheduled processing

The live function runs every 10 minutes, while historical processing was handled as a separate controlled workflow.

Duplicate prevention

Previously processed messages are skipped so the tracker and Drive do not receive repeated entries from the same source message.

Attachment-level filing

Each attachment can be classified and stored independently rather than forcing every file in one email into the same category.

Operational controls

Outgoing-message screening, controlled batch limits, error logging, manual-review status, and chronological sorting support reliability.

Simplified logic

Readable pseudocode instead of confidential source code.

The complete internal script is not published. This excerpt communicates the workflow design without exposing IDs, account details, keywords, or organization-specific rules.

every 10 minutes:
  search recent incoming messages

  for each message:
    skip outgoing or already-processed items
    screen relevance

    for each attachment:
      classify document
      create year / month / section / category path
      save file to Drive

    append communication details to Sheets
    record processing status or error

  sort register from oldest to newest
